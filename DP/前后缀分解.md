# [2163. 删除元素后和的最小差值](https://leetcode.cn/problems/minimum-difference-in-sums-after-removal-of-elements/)
给你一个下标从 **0** 开始的整数数组 `nums` ，它包含 `3 * n` 个元素。

你可以从 `nums` 中删除 **恰好** `n` 个元素，剩下的 `2 * n` 个元素将会被分成两个 **相同大小** 的部分。

- 前面 `n` 个元素属于第一部分，它们的和记为 `sumfirst` 。
- 后面 `n` 个元素属于第二部分，它们的和记为 `sumsecond` 。

两部分和的 **差值** 记为 `sumfirst - sumsecond` 。

- 比方说，`sumfirst = 3` 且 `sumsecond = 2` ，它们的差值为 `1` 。
- 再比方，`sumfirst = 2` 且 `sumsecond = 3` ，它们的差值为 `-1` 。

请你返回删除 `n` 个元素之后，剩下两部分和的 **差值的最小值** 是多少。


```python
class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        import heapq

        n = len(nums) // 3

        # Maintain a max heap for the left part to always keep the n smallest elements' sum
        # 最大堆
        left_heap = [-x for x in nums[:n]] # python 默认是最小堆，所以需要取负号
        heapq.heapify(left_heap)
        left_sum = sum(nums[:n])
        left_sums = [left_sum]

        for i in range(n, 2 * n):
            heapq.heappush(left_heap, -nums[i])
            left_sum += nums[i] + heapq.heappop(left_heap)
            left_sums.append(left_sum)

        # Maintain a min heap for the right part to always keep the n largest elements' sum
        right_heap = nums[2 * n:]
        heapq.heapify(right_heap)
        right_sum = sum(nums[2 * n:])
        right_sums = [right_sum]

        for i in range(2 * n - 1, n - 1, -1):
            heapq.heappush(right_heap, nums[i])
            right_sum += nums[i] - heapq.heappop(right_heap)
            right_sums.append(right_sum)

        right_sums = right_sums[::-1]

        # 遍历每一个可能的分割点，计算左右两部分的差值
        res = float('inf')
        for i in range(n + 1):
            res = min(res, left_sums[i] - right_sums[i])

        return res
```

# [3302. 字典序最小的合法序列](https://leetcode.cn/problems/find-the-lexicographically-smallest-valid-sequence/)
给你两个字符串 `word1` 和 `word2` 。

如果一个字符串 `x` 修改 **至多** 一个字符会变成 `y` ，那么我们称它与 `y` **几乎相等** 。

如果一个下标序列 `seq` 满足以下条件，我们称它是 **合法的** ：

- 下标序列是 **升序** 的**。**
- 将 `word1` 中这些下标对应的字符 **按顺序** 连接，得到一个与 `word2` **几乎相等** 的字符串。

请你返回一个长度为 `word2.length` 的数组，表示一个 字典序最小 的 **合法** 下标序列。如果不存在这样的序列，请你返回一个 **空** 数组。

**注意** ，答案数组必须是字典序最小的下标数组，而 **不是** 由这些下标连接形成的字符串。

> 我们不妨先想想，假如说题目不允许修改字母，我们应该怎么做。
> 其实很简单，我们只需要正向遍历，然后挨个匹配就好了。 所以难点在于，现在题目允许我们进行一次修改。
> 为了保证字典序最小，所以正常应该在第一次没匹配上时，就直接修改。
> - 但这也会带来一个问题，看例子。word1 = "baac"，word2 = "abc"，如果我们在第一个位置直接用掉这次修改机会，你会发现后面就无法完全匹配了。但实际上如果我们把修改机会留到后面，把第二个a改成b，是可以匹配上的。 所以用还是不用这次修改机会，是要取决于用完之后，后面的字符串还有没有机会完全匹配上的。
> - 这就让我们必须知道未来的信息，于是才想到了**后缀数组**。 
> 
> 1. 我们先把word1每个位置能匹配上的后缀数组算出来。
> 2. 当我们正向遍历时，我们会记录下当前已经匹配了几个字符，同时我们还知道未来最多还能匹配几个字符。 
> 3. 当我们需要修改字符时，我们把这个修改后的字符算作匹配上的，然后再看后面的字符，还能匹配几个。比如我们上面的例子里，如果我们把word1的第一个b改成了a，那么现在匹配上了一个，后缀部分还能再匹配一个，总共2个，但我们总共需要匹配3个，并不满足条件，所以不能在此处翻转。然后如果我们把第二个a改成了b，那么当前一共匹配上了2个，后缀部分还有一个可以匹配，满足条件。

```python
class Solution:
    def validSequence(self, word1: str, word2: str) -> List[int]:
        m, n = len(word1), len(word2)
        suf = [0] * (m + 1) # 代表 word1[i:] 和 word2[j:] 的最长公共前缀长度
        j = n - 1
        for i in range(m - 1, -1, -1):
            if j >= 0 and word1[i] == word2[j]:
                suf[i] = suf[i + 1] + 1
                j -= 1
            else:
                suf[i] = suf[i + 1]
        
        # 计算公共前缀，如果前缀+后缀的长度大于等于n, 证明匹配上了
        res = []
        changed = False # 有且仅有一次修改机会
        j = 0
        for i in range(m):
            if j == n:
                return res
            if word1[i] == word2[j]:
                res.append(i)
                j += 1
            # 如果不匹配, 但是后缀长度+当前匹配长度大于等于n, 证明可以修改一次匹配上
            elif not changed and suf[i + 1] + (j + 1) >= n:
                res.append(i)
                changed = True
                j += 1
        return res if j == n else []
```
