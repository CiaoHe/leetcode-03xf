# [3534. 针对图的路径存在性查询 II](https://leetcode.cn/problems/path-existence-queries-in-a-graph-ii/)

[[3532. 针对图的路径存在性查询 I](https://leetcode.cn/problems/path-existence-queries-in-a-graph-i/)](leetcode/并查集/基础.md#[3532.%20针对图的路径存在性查询%20I](https%20//leetcode.cn/problems/path-existence-queries-in-a-graph-i/)) 原来是用unionFind就可以找到，但是空间占用太高 & 无法快速计算最小距离 -> 这里得用双指针确定排序前后index的对应关系 + 尝试倍增法找到最大可跳跃的step

给你一个整数 `n`，表示图中的节点数量，这些节点按从 `0` 到 `n - 1` 编号。

同时给你一个长度为 `n` 的整数数组 `nums`，以及一个整数 `maxDiff`。

如果满足 `|nums[i] - nums[j]| <= maxDiff`（即 `nums[i]` 和 `nums[j]` 的 **绝对差** 至多为 `maxDiff`），则节点 `i` 和节点 `j` 之间存在一条 **无向边** 。

此外，给你一个二维整数数组 `queries`。对于每个 `queries[i] = [ui, vi]`，找到节点 `ui` 和节点 `vi` 之间的 **最短距离** 。如果两节点之间不存在路径，则返回 -1。

返回一个数组 `answer`，其中 `answer[i]` 是第 `i` 个查询的结果。

**注意：**节点之间的边是无权重（unweighted）的。

> 1. 为了方便判断边，会按照nums排序。因此我们需要记录一下排序之后原来的节点编号对应的是排序后的哪个位置
> 2. `right` 理解成一个“快捷表”：从每个位置出发，一步能跳到的最远位置。这样就可以不用真的建图去记录每个节点究竟可以和谁直接相连

```python
class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int], maxDiff: int, queries: List[List[int]]) -> List[bool]:
        # 按照nums的值排序，同时记录原来的下标
        nodes = sorted([(num, i) for i, num in enumerate(nums)])
        vals = [num for num, _ in nodes]

        # 原来的节点编号 -> 排序后的节点编号
        pos = [0] * n
        for i, (_, idx) in enumerate(nodes):
            pos[idx] = i
        
        # 判断联通块，如果排序后相邻两个num的差值大于maxDiff，则它们不在同一个联通块中
        comp = [0] * n
        for i in range(1, n):
            if vals[i] - vals[i-1] > maxDiff:
                comp[i] = comp[i-1] + 1
            else:
                comp[i] = comp[i-1]
        
        # right[i] 表示从节点i出发，能到达的最右边的节点编号
        right = [0] * n
        r = 0
        for i in range(n):
            while r+1 < n and vals[r+1] - vals[i] <= maxDiff:
                r += 1
            right[i] = r
            
        # jump[k][i] 表示从节点i出发，跳2^k步能到达的节点编号
        LOG = n.bit_length()
        jump = [[0] * n for _ in range(LOG)]
        jump[0] = right # right是为了知道“从排序后某个位置出发，一步最多能走多远”。
        # 所以2^0=1, 即jump[0]就是right
        for k in range(1, LOG):
            for i in range(n):
                mid = jump[k-1][i]
                jump[k][i] = jump[k-1][mid]
            
        ans = []
        for u, v in queries:
            u_pos = pos[u]
            v_pos = pos[v]
            if u_pos == v_pos:
                ans.append(0)
                continue
            # 保证从小的编号出发
            if u_pos > v_pos:
                u_pos, v_pos = v_pos, u_pos
            
            # 如果不在同一个联通块中，则无法到达
            if comp[u_pos] != comp[v_pos]:
                ans.append(-1)
                continue

            # 尽可能多跳
            cur = u_pos
            steps = 0
            for k in range(LOG-1, -1, -1):
                nxt = jump[k][cur]
                if nxt < v_pos:
                    cur = nxt
                    steps += 1 << k
            # 最后一步还需要再跳一下
            if cur < v_pos:
                steps += 1
            ans.append(steps)
        return ans
```
