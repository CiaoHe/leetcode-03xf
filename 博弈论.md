# [913. 猫和老鼠](https://leetcode.cn/problems/cat-and-mouse/)
之前用dfs会超时，现在只能用bfs+dp
```python
class Solution:
    def catMouseGame(self, graph: List[List[int]]) -> int:
        n = len(graph)
        # dp[mouse][cat][turn]
        dp = [[[0,0] for _ in range(n)] for _ in range(n)]
        queue = deque()

        # init
        for i in range(1, n):
            for t in range(2): # 0: mouse, 1: cat
                dp[0][i][t] = 1 # mouse win
                queue.append((0, i, t, 1))
                if i != 0:
                    dp[i][i][t] = 2 # cat win
                    queue.append((i, i, t, 2))
        
        while queue:
            mouse, cat, turn, result = queue.popleft()
            if turn == 0: # mouse turn, 上一个回合是cat
                for prev_cat in graph[cat]:
                    if prev_cat == 0: # cat can't be at 0
                        continue
                    if dp[mouse][prev_cat][1] == 0: # 如果状态还没有确定
                        if result == 2: # 如果猫win, 则上一个状态是猫win
                            dp[mouse][prev_cat][1] = 2
                            queue.append((mouse, prev_cat, 1, 2))
                        else:
                            # 检查是否所有猫的移动都导致老鼠赢
                            all_mouse_win = True
                            for next_cat in graph[prev_cat]:
                               if next_cat == 0:
                                   continue
                               if dp[mouse][next_cat][0] != 1:
                                   all_mouse_win = False
                                   break
                            if all_mouse_win:
                                dp[mouse][prev_cat][1] = 1
                                queue.append((mouse, prev_cat, 1, 1))
            else: # cat turn, 上一个回合是mouse
                for prev_mouse in graph[mouse]:
                    if dp[prev_mouse][cat][0] == 0: # 如果状态还没有确定
                        if result == 1: # 如果老鼠win, 则上一个状态是老鼠win
                            dp[prev_mouse][cat][0] = 1
                            queue.append((prev_mouse, cat, 0, 1))
                        else:
                            if all(dp[next_mouse][cat][1] == 2 for next_mouse in graph[prev_mouse]):
                                dp[prev_mouse][cat][0] = 2
                                queue.append((prev_mouse, cat, 0, 2))
        return dp[1][2][0]
```
# [1728. 猫和老鼠 II](https://leetcode.cn/problems/cat-and-mouse-ii/)
注意剪枝：最多可以走的步数小于2*`所有空白的数目`
```python
class Solution:
    def canMouseWin(self, grid: List[str], catJump: int, mouseJump: int) -> bool:
        m, n = len(grid), len(grid[0])
        walls = set()
        for i, row in enumerate(grid):
            for j, cell in enumerate(row):
                if cell == 'M':
                    mouse = (i, j)
                elif cell == 'C':
                    cat = (i, j)
                elif cell == 'F':
                    food = (i, j)
                elif cell == '#':
                    walls.add((i, j))
        
        def in_bounds(x, y):
            return 0 <= x < m and 0 <= y < n
        
        @lru_cache(None)
        def dfs(mouse, cat, turns):
            """如果猫跟老鼠处在相同的位置，那么猫获胜。
            如果猫先到达食物，那么猫获胜。
            如果老鼠先到达食物，那么老鼠获胜。
            如果老鼠不能在 1000 次操作以内到达食物，那么猫获胜。"""
            if cat == mouse or cat == food or turns > 1000:
                return False
            if mouse == food:
                return True
            
            # mouse move
            if turns % 2 == 0:
                i,j = mouse
                for di,dj in [(-1,0), (1,0), (0,-1), (0,1)]:
                    for jump in range(mouseJump + 1):
                        ni,nj = i + di * jump, j + dj * jump
                        if not in_bounds(ni, nj) or (ni, nj) in walls:
                            break
                        if dfs((ni, nj), cat, turns + 1):
                            return True
                return False
            # cat move
            else:
                i,j = cat
                for di,dj in [(-1,0), (1,0), (0,-1), (0,1)]:
                    for jump in range(catJump + 1):
                        ni,nj = i + di * jump, j + dj * jump
                        if not in_bounds(ni, nj) or (ni, nj) in walls:
                            break
                        # 如果沿着当前的走法走下去，有一种结局是猫win，那么猫绝对会沿着这种方案去做，所以直接返回False
                        if not dfs(mouse, (ni, nj), turns + 1):
                            return False
                # 只有当所有从当前位置发展下去的结局都保证猫不能win，那么鼠鼠才能win
                return True

        return dfs(mouse, cat, 0)
```

# [1927. 求和游戏](https://leetcode.cn/problems/sum-game/)
Alice 和 Bob 玩一个游戏，两人轮流行动，**Alice 先手** 。

给你一个 **偶数长度** 的字符串 `num` ，每一个字符为数字字符或者 `'?'` 。每一次操作中，如果 `num` 中至少有一个 `'?'` ，那么玩家可以执行以下操作：

1. 选择一个下标 `i` 满足 `num[i] == '?'` 。
2. 将 `num[i]` 用 `'0'` 到 `'9'` 之间的一个数字字符替代。

当 `num` 中没有 `'?'` 时，游戏结束。

Bob 获胜的条件是 `num` 中前一半数字的和 **等于** 后一半数字的和。Alice 获胜的条件是前一半的和与后一半的和 **不相等** 。

- 比方说，游戏结束时 `num = "243801"` ，那么 Bob 获胜，因为 `2+4+3 = 8+0+1` 。如果游戏结束时 `num = "243803"` ，那么 Alice 获胜，因为 `2+4+3 != 8+0+3` 。

在 Alice 和 Bob 都采取 **最优** 策略的前提下，如果 Alice 获胜，请返回 `true` ，如果 Bob 获胜，请返回 `false` 。

- 如果总？数目是odd, alice因为先手，永远可以有最后一个修改？的机会让前后两部分不等
- 否则
	- 假设一共两个问号
		- 如果左半右半各有一个问号
			- 如果 $S_L = S_R$, 那么 Alice 把问号改成 x, Bob **模仿**，把另一个问号也改成 x。最终 $S_L​=S_R$​，Bob 获胜。
			- 如果 $S_L > S_R$,  alice可以把左边问号改成9，alice必赢
			- 如果 $S_L < S_R$,  alice可以把右边问号改成9，alice必赢
		- 如果两个问号都在左
			- 如果$S_R - S_L = 9$, 那么 Alice 把一个问号改成 x，Bob 只需把另一个问号改成 9−x，就可以使左半和恰好增加 9。最后bob wins
			- 否则无论怎样都是alice wins
	- 那么推论设左半的问号个数为$q_L$​，右半的问号个数为 $q_R$​. 当且仅当 $S_R - S_L = \frac{q_L- q_R}{2} * 9$  Bob 获胜

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        n = len(num)
        sum1, sum2 = 0, 0
        cnt1, cnt2 = 0, 0
        # 对前半部分和后半部分分别统计数字和问号的数量
        for i in range(n//2):
            if num[i] == '?':
                cnt1 += 1
            else:
                sum1 += int(num[i])
        # 对后半部分和后半部分分别统计数字和问号的数量
        for i in range(n//2, n):
            if num[i] == '?':
                cnt2 += 1
            else:
                sum2 += int(num[i])
        # 如果问号的总数是奇数，那么Alice一定会赢
        # 因为Alice可以通过选择一个问号来改变前后部分的和，从而确保她赢得比赛
        if (cnt1 + cnt2) % 2 == 1:
            return True
        return sum1 + (cnt1 // 2) * 9 != sum2 + (cnt2 // 2) * 9
```
