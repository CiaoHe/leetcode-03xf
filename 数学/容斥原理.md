# [2929. 给小朋友们分糖果 II](https://leetcode.cn/problems/distribute-candies-among-children-ii/)
给你两个正整数 `n` 和 `limit` 。

请你将 `n` 颗糖果分给 `3` 位小朋友，确保没有任何小朋友得到超过 `limit` 颗糖果，请你返回满足此条件下的 **总方案数** 。

```python
# 所有方案数目: n个无区别的球放在3个有区别的盒子里，允许空盒子
# C(n+2, 2)

# 至少一个小朋友分到>limit个糖果的方案数目
# 3 * C(n-(limit+1)+2, 2) = 3 * C(n-limit+1, 2)

# 至少两个小朋友分到>limit个糖果的方案数目
# 3 * C(n-2(limit+1)+2, 2) = 3 * C(n-2*limit, 2)

# 至少三个小朋友分到>limit个糖果的方案数目
# C(n-3(limit+1)+2, 2) = C(n-3*limit-1, 2)
```

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def c2(n):
            if n<=1:
                return 0
            return n * (n-1) // 2

        return c2(n+2) - 3 * c2(n-limit+1) + 3 * c2(n-2*limit) - c2(n-3*limit-1)
```

# [3116. 单面值组合的第 K 小金额](https://leetcode.cn/problems/kth-smallest-amount-with-single-denomination-combination/)
给你一个整数数组 `coins` 表示不同面额的硬币，另给你一个整数 `k` 。

你有无限量的每种面额的硬币。但是，你 **不能** 组合使用不同面额的硬币。

返回使用这些硬币能制造的 **第** `kth` **小** 金额。

> 二分法

我们需要统计 **≤ m 且能被至少一种硬币面额整除**​ 的正整数的个数。直接相加会重复计数（比如同时被 2 和 3 整除的数会被算两次），所以要用容斥原理：$count=∑​_{非空子集 S}(−1)^{∣S∣+1}⌊\frac{m}{lcm(S)}​⌋$

其中 $lcm(S)$ 是子集 S 中所有面额的最小公倍数，⌊m/lcm(S)⌋ 表示 ≤ m 且能被该子集中所有面额整除的数的个数。
- 当子集大小为奇数时，$(−1)^{∣S∣+1=+1}$，所以**加**；
- 当子集大小为偶数时，$(−1)^{∣S∣+1}=−1$，所以**减**

```python
class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        # 二分法 容斥原理
        n = len(coins)
        def check(m:int) -> bool:
            # 检查当前猜测的金额上限
            
            # check(m) 使用容斥原理计算 ≤ m 且能被至少一种硬币面额整除的正整数个数，然后判断这个个数是否 ≥ k
            count = 0
            
            # 枚举子集是为了处理不同面额之间的重叠计数，而非要求同时使用多种面额
            for i in range(1, 1 << n): # 遍历所有非空子集
                lcm_res = 1
                for j,x in enumerate(coins):
                    if (i >> j) & 1: # 如果第 j 个硬币被选中
                        lcm_res = lcm(lcm_res, x) 
                        if lcm_res > m: # 如果 lcm 已经大于 m, 那么这个子集的贡献为 0
                            break
                else: # 如果 lcm_res <= m
                    if bin(i).count('1') % 2: # 如果子集大小为奇数
                        count += m // lcm_res
                    else: # 如果子集大小为偶数
                        count -= m // lcm_res
            return count >= k
        
        return bisect_left(range(min(coins)*k), True, k, key=check)
```
