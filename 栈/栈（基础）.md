# [402. 移掉 K 位数字](https://leetcode.cn/problems/remove-k-digits/)
```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        if len(num) <= k:
            return "0"
        # 思考：用栈来实现
        # 栈顶元素是当前最小的元素，如果当前元素比栈顶元素小，则弹出栈顶元素
        st = []
        for c in num:
            while st and st[-1] > c and k > 0:
                st.pop()
                k -= 1
            st.append(c)
        # 如果k还有剩余，则从栈顶弹出k个元素
        while k > 0:
            st.pop()
            k -= 1
        res = "".join(st).lstrip("0")
        return res if res else "0"
```

# [394. 字符串解码](https://leetcode.cn/problems/decode-string/)
采用辅助栈
- 遇到`[`时把(multi, res)压入stack中
- 遇到`]`把multi, 和last_res 弹出，然后把当前的res x multi之后 拼接到 last_res后面
```python
class Solution:
    def decodeString(self, s: str) -> str:
        st = []
        res = ''
        multi = 0
        for i,c in enumerate(s):
            if c.isdigit():
                multi = multi*10 + int(c)
            elif c=='[':
                st.append([multi, res])
                multi,res = 0,''
            elif c==']':
                cur_multi, lastres = st.pop()
                res = lastres + cur_multi * res
            else:
                res += c
        return res
```
采用递归的做法

```python
class Solution:
    def decodeString(self, s: str) -> str:
        # 思路：用dfs解决
        n = len(s)
        def dfs(idx:int) -> Tuple[int, str]:
            # 返回当前遍历到的idx和解码后的字符串
            res = ''
            multiplier = 0
            while idx < n:
                if s[idx].isdigit():
                    multiplier = multiplier * 10 + int(s[idx])
                elif s[idx] == '[':
                    idx, sub_res = dfs(idx+1)
                    res += multiplier * sub_res
                    multiplier = 0
                elif s[idx] == ']':
                    return idx, res
                else:
                    res += s[idx]
                idx += 1
            return idx, res
        return dfs(0)[1]
```
# [1190. 反转每对括号间的子串](https://leetcode.cn/problems/reverse-substrings-between-each-pair-of-parentheses/)
给出一个字符串 `s`（仅含有小写英文字母和括号）。

请你按照从括号内到外的顺序，逐层反转每对匹配括号中的字符串，并返回最终的结果。

注意，您的结果中 **不应** 包含任何括号。

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        # 使用stack来处理括号
        stack = []
        for c in s:
            if c == ')':
                # 遇到右括号，弹出直到遇到左括号
                temp = [] # 存储反转的内容
                while stack and stack[-1] != '(':
                    temp.append(stack.pop())
                stack.pop()  # 弹出左括号
                stack.extend(temp)  # 将反转的内容放回栈中
            else:
                stack.append(c)
        return ''.join(stack)
```

# [1614. 括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/)
给定 **有效括号字符串** `s`，返回 `s` 的 **嵌套深度**。嵌套深度是嵌套括号的 **最大** 数量。
```python
class Solution:
    def maxDepth(self, s: str) -> int:
        cur_depth = 0
        max_depth = 0
        for char in s:
            if char == '(':
                cur_depth+=1
                max_depth = max(max_depth, cur_depth)
            elif char == ')':
                cur_depth-=1
        return max_depth
```
