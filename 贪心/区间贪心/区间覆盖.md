# [1326. 灌溉花园的最少水龙头数目](https://leetcode.cn/problems/minimum-number-of-taps-to-open-to-water-a-garden/)
思考：
1. 需要先做出来每个`i`的位置能够到达的最右边的pos: 维护`right_most[i]` 
2. 在45的基础上需要考虑：如果我已经能走到我现在最远能走到的右端点，但是我还没能到达终点怎么办？ `return -1`
```python
class Solution:
    def minTaps(self, n: int, ranges: List[int]) -> int:
        ans = 0
        right_most = [0]*(n+1)
        for i, r in enumerate(ranges):
            left = max(0, i-r)
            right = i+r
            # 所以从left开始最多能expand到的右边位置:
            right_most[left] = max(right_most[left], right)
        
        cur_right=0
        max_right=0
        for i in range(n):
            max_right = max(max_right, right_most[i])
            if i>=max_right: # 如果我已经能走到我现在最远能走到的右端点
                return -1
            if i==cur_right:
                ans+=1
                cur_right=max_right
        return ans
```
# [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)
### 从后往前
```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        step = 0
        pos = n-1
        while pos:
            # 尽可能从更远的地方开始
            for i in range(pos):
                if i+nums[i] >= pos:
                    pos = i
                    step += 1
                    break
        return step
```
### 从前往后
思考：
- 这里遍历只到n-2的位置, 因为如果到了i=n-2, 那么一定会从n-2向n-1延伸一个新的桥(since $nums[i]>1$)
```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        step = 0
        cur_right = 0 # 当前桥的右端点
        max_right = 0 # 目测下一座桥的右端点
        for i in range(n-1):
            max_right = max(i+nums[i], max_right)
            if i==cur_right:
                # 已经走到了桥的边缘，需要找到新的右端点
                step += 1
                cur_right=max_right
        return step
```

# [1288. 删除被覆盖区间](https://leetcode.cn/problems/remove-covered-intervals/)
给你一个区间列表，请你删除列表中被其他区间所覆盖的区间。

只有当 `c <= a` 且 `b <= d` 时，我们才认为区间 `[a,b)` 被区间 `[c,d)` 覆盖。

在完成所有删除操作后，请你返回列表中剩余区间的数目。

```python
class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        # Sort intervals by start time, and if equal, by end time in descending order
        intervals.sort(key=lambda x: (x[0], -x[1]))
        n = len(intervals)
        count = 0
        max_end = 0 # Initialize the maximum end point seen so far
        # 枚举每个区间，判断是否被覆盖
        for start, end in intervals:
            if end > max_end: # 说明当前区间的右端点大于之前的最大右端点，说明当前区间没有被覆盖
                count += 1
                max_end = end
        return count
```
